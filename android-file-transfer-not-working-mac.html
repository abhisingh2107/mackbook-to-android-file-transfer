Android File Transfer Not Working on Mac? 9 Fixes That Work

You plug your Android phone into your MacBook, and nothing happens. Android File Transfer says it can't connect, or the phone doesn't show up at all. This is a common problem, and it is usually caused by something small. Work through the fixes below in order, because the first few solve most cases.

1. Use a real data cable

Many cables that come with accessories only charge. If your Mac doesn't see the phone at all, try the cable that came with your phone, or another one you know can move data. Avoid very long or very cheap cables.

2. Unlock the phone and set USB mode to File transfer

After plugging in, unlock the screen. Pull down the notification shade, tap the USB notification (for example "Charging this device via USB"), and choose File transfer. If the mode stays on "No data transfer" or "Charging only", the Mac can't read your storage.

3. Try another port and skip the hub

Plug directly into a USB-C port on the Mac. Adapters and hubs often cause dropouts. If your MacBook has two or more ports, try each one.

4. Allow the accessory on your Mac

On newer MacBooks, macOS may ask whether to allow a USB accessory to connect. If you dismissed the prompt, unplug and plug the phone back in and approve it. You can also check System Settings → Privacy & Security for accessory permissions.

5. Close apps that grab the phone

Only one program can use the phone's USB connection at a time. Quit Android Studio, Samsung Smart Switch, and any other phone manager. If you've used adb before, open Terminal and run:

adb kill-server

If the Android File Transfer helper is stuck, quit the app from the menu bar and open it again.

6. Restart the phone and the Mac

It sounds basic, but a restart clears USB glitches on both sides. Restart both devices, then reconnect with the phone unlocked.

7. Check that the app is allowed to read files

Android File Transfer is an older app and may need permission to work with files on your Mac. Look under System Settings → Privacy & Security → Files and Folders (or Full Disk Access) and make sure it is allowed. Keep in mind that this app is no longer actively updated, so it can misbehave on recent macOS versions.

8. Turn on USB debugging (and re-approve the Mac)

Go to Settings → About phone, tap Build number 7 times, then open Developer options and enable USB debugging. If you previously approved this Mac, you can use Revoke USB debugging authorizations and approve again when prompted.

9. Skip the app: transfer in your browser

If Android File Transfer keeps failing, you can move files with a browser-based tool that uses your USB-C cable. It runs in Chrome or Edge, needs no install, and sends files directly between the two devices, not through the cloud. You need USB debugging on (step 8), then you connect, tap Allow on the phone, and browse your phone's folders.

Frequently asked questions

Why does my Mac not detect my Android phone?
Most often it is a charge-only cable, USB mode not set to File transfer, a locked screen, or another program holding the connection.

Does this work on Apple silicon MacBooks?
The connection steps are the same. Use a direct USB-C port and approve any accessory prompt.

Is my data safe when I transfer by USB?
Yes. The files travel over the cable between your devices. With the browser tool, nothing is uploaded to a server.

Still stuck?
Note the exact error message and your phone model, then try a different cable and port first. Those two fix the majority of cases.
